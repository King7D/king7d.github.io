MISSION BRIEF

NeuraQuant automates the research loop of a quantitative analyst. Describe a research direction in plain language — e.g. "price-volume factor mining" — and a team of LLM agents plans diversified hypotheses, writes the factor code, evolves it across trajectories, and validates every candidate with real backtests. The output is a growing library of alpha factors, each shipped with its full performance record.

The engine is adapted end-to-end for single-asset crypto trading on Binance BTC/USDT: validation was redesigned around time-series information coefficients, cross-sectional operators are disabled at the prompt and regulator level, and the whole stack runs on a local LLM (Ollama · qwen3-coder 30B) — no cloud API required.

SYSTEM ARCHITECTURE

01 // Diversified Planning

A natural-language research direction is expanded by LLM agents into multiple diversified factor hypotheses, each paired with a structured hypothesis-to-code constraint so that generated factor expressions stay faithful to their economic rationale.

02 // Trajectory-Level Self-Evolution

Each hypothesis evolves along its own trajectory: generate factor code → execute on price-volume data → score → mutate and retry. A factor regulator enforces hard constraints — any cross-sectional operator (meaningless on a single asset) is rejected and regenerated with time-series operators (TS_*) only.

03 // Time-Series Validation

Because cross-sectional IC is mathematically undefined for one asset, NeuraQuant scores factors with a custom time-series IC: monthly-bucketed correlation between factor values and forward BTC returns. Every factor is automatically backfilled with IC, ICIR, Rank IC, annualized return, Sharpe ratio and max drawdown before it enters the library.

04 // Factor Library & Independent Backtest

Validated factors accumulate in a JSON factor library that can be browsed, filtered and combined from the web dashboard. Selected factors are then run through full-period Qlib backtests on 2019–2025 BTC data, with equity curves and risk metrics rendered visually.

05 // One-Click Local Deployment

The entire system — mining backend, backtest engine, and React dashboard — launches with a single command and streams real-time experiment logs to the browser. Inference runs fully offline through Ollama, keeping research private and cost-free.

WHY IT MATTERS

Classical factor research is a slow human loop: hypothesize, code, backtest, discard, repeat. NeuraQuant turns that loop into an autonomous factory — LLM agents generate and stress-test hundreds of candidate alphas while the researcher only steers the direction. It is a working prototype of self-evolving AI applied to systematic crypto trading.

ENGINEERING HIGHLIGHTS

  • Re-architected an A-share cross-sectional pipeline into a single-asset BTC engine
  • Custom time-series IC / ICIR metrics replacing undefined cross-sectional statistics
  • Prompt + regulator double guardrails forcing valid TS_* factor expressions
  • Deterministic metric-backfill tool rebuilding factor stats straight from expressions
  • Full local stack: Ollama LLM, Qlib backtests, React dashboard, one-click launch
