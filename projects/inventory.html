INVENTORY TRACKING SYSTEM

Flask + SQLAlchemy Inventory Management

MISSION BRIEF

A web-based inventory tracking system built with Flask and SQLAlchemy, designed to manage inventory items with full CSV import/export support.

SYS_UI // INVENTORY DASHBOARD

KEY FEATURES

  • CRUD operations: create, read, update, and delete inventory items.
  • CSV Import/Export: export the inventory list to CSV and import inventory data from CSV, replacing old data.
  • Sorting: sort items by date, name, ID, quantity, or price in ascending or descending order.
  • Flash Messages: informative feedback displayed after each action.
  • User-Friendly UI: responsive, intuitive design with action buttons that works across screen sizes and devices.

TECHNOLOGY STACK

  • Backend: Flask (Python), SQLAlchemy (SQLite database)
  • Frontend: HTML, CSS
  • CSV Support: Python csv module for file handling
