DIGIT CLASSIFICATION

k-NN Handwritten Digit Recognition Pipeline

MISSION BRIEF

Handwritten digit recognition is a canonical computer-vision and pattern-recognition task. This project builds a classifier that accurately recognizes digits from raw pixel data using the k-NN algorithm, tuned and evaluated end-to-end.

PIPELINE FEATURES

  • Data Preprocessing: normalize pixel data and combine with corresponding labels for both training and testing datasets.
  • Model Tuning: cross-validation determines the optimal number of neighbors for the k-NN classifier.
  • Model Evaluation: accuracy metrics and a confusion matrix quantify classifier performance.
  • Visualization: insight into how well the model recognizes patterns in the data.

LIBRARIES

  • tidyverse: data manipulation and visualization
  • tidymodels: model building, preprocessing, and evaluation
  • kknn: k-NN algorithm implementation
  • ggplot2: plotting · repr: output control
